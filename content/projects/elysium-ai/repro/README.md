# Elysium AI Reproduction Demo

This directory contains a minimal reproducible demo of the Elysium AI multi-agent system.

## Quick Start

```bash
make reproduce
```

## Architecture

The demo includes:

- **Perception**: Real-time affective state processing
- **Multi-Agent Core**: Emotionally aware agents with MCP
- **Memory**: RAG-based context sharing
- **Action**: Adaptive behavior controller
