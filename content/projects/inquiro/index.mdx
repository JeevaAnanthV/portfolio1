# Inquiro

Multimodal RAG Chatbot System. Developed chatbot integrating PDF, web, and video sources using LangChain + Google Generative AI.

## Overview

Inquiro is a multimodal RAG (Retrieval-Augmented Generation) chatbot system that integrates diverse content sources including PDFs, web pages, and video content. The system leverages LangChain and Google Generative AI to provide accurate, contextually relevant responses.

## Key Achievements

- **Implemented Retriever-Augmented Generation (RAG) with Chroma Vector DB**
- **Improved contextual accuracy by 90%**
- **Multimodal content integration (PDF, web, video)**

## Architecture

The system processes multiple content types:

1. **Ingestion Layer**: PDF, Web, Video sources using Scrapy and LangChain
2. **Vectorization Layer**: Multimodal embeddings using Google GenAI
3. **Retriever Layer**: Vector search with ChromaDB
4. **RAG Engine**: Generative response using Google GenAI and LangChain

## Technologies

- **ML/AI**: LangChain, Google Generative AI
- **Vector Database**: ChromaDB
- **Content Processing**: Scrapy, Multimodal embeddings
- **Language**: Python

## Impact

Inquiro achieved a 90% improvement in contextual accuracy by effectively integrating and retrieving information from diverse multimodal sources.
